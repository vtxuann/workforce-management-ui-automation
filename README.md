# Workforce Management System - UI Automation Framework

## Overview

End-to-end UI automation framework for a workforce management system using Playwright and TypeScript.

The system under test is based on OrangeHRM Open Source and is hosted locally using Docker.

## Tech Stack

- Playwright
- TypeScript
- Node.js
- Docker
- Docker Compose
- Git
- GitHub Actions

## Test Scope

- Authentication
- Dashboard
- Employee Management
- Leave Management
